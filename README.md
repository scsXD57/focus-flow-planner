
A lightweight, distraction-free study timer and prioritized task tracker built with HTML, CSS, and Vanilla JavaScript.

## Features
- **Pomodoro Timer:** Switch seamlessly between 25-minute Focus sessions, 5-minute Short Breaks, and 15-minute Long Breaks.
- **Prioritized Task List:** Add study tasks with High, Medium, or Low priority tags.
- **Persistent Storage:** Automatically saves tasks in the browser's `localStorage` so your study list stays intact even if you refresh or close the tab.

## How to Run
Simply open `index.html` in any modern web browser, or visit the live GitHub Pages deployment.
